## Host free using GitHub Pages
1. Create a public GitHub repository, e.g. `student-portfolio`.
2. Upload all six files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. After deployment, the site will be available at `https://YOUR-USERNAME.github.io/student-portfolio/`.
